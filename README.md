# React project style guides

These guides define shared conventions for first-party React, React Native, and TypeScript projects:

- [Coding style](coding-style.md) covers source, tests, examples, comments, and review.
- [Markdown source style](documentation-style.md) covers paragraph layout, code fences, and links. The [technical-writing skill](https://github.com/riekelt/technical-writer/blob/main/plugins/technical-writer/skills/technical-writing/SKILL.md) owns substantive technical prose.

Projects adopt a tagged release by linking both guides from their `AGENTS.md`. Local instructions may add domain rules, framework-required exceptions, and scoped migration notes.

Projects should reference the [Ponytail skill](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md) separately in `AGENTS.md` for task scope and verification. Where its advice about comments or small helpers differs, follow this guide for code style.

Vite+ is preferred for new projects. A canonical Vite+ configuration and migrations from other formatters are separate work.
